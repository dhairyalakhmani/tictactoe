# 🎮 Tic Tac Toe — Web Project

A fun, minimalistic **Tic Tac Toe game** built using **HTML, CSS, and JavaScript** as part of my **Unified Mentor Project 2**.

---

## 🧩 Overview

This project is a browser-based Tic Tac Toe game that lets you play in two modes:
- **Single Player:** Play against a simple computer bot (random moves).
- **Two Players:** Play locally with a friend on the same device.

The interface is clean, responsive, and visually enhanced with a soft gradient background and smooth animations.

---

## ⚙️ Features

✅ **Two Game Modes** – Single player (vs computer) & double player (vs friend)  
✅ **Scoreboard Tracking** – Keeps track of wins for both players  
✅ **Reset Option** – Easily reset scores and start fresh  
✅ **Interactive UI** – Hover effects, shadows, and smooth transitions  
✅ **Fully Responsive** – Works well on desktop and mobile browsers  

---

## 🖼️ Preview

The layout consists of:
- Title and description  
- A scoreboard section  
- Buttons to choose game mode and reset scores  
- A 3×3 interactive grid  
- A message display showing game status (turns or results)
